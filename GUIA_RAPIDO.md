# 🏥 Sistema de Chamados - Guia Rápido

**Acesso:** <http://chamados.hospital.local>

---

## 👤 Para Solicitantes (Funcionários)

### Como criar um chamado

1. Acesse o sistema e faça login
2. Clique no setor desejado (Ex: TI, Manutenção)
3. Preencha: **Título**, **Descrição**, **Local**
4. Selecione a **Prioridade**
5. Anexe foto se necessário
6. Clique em **Criar Chamado**

### Acompanhar seu chamado

- Acesse "Meus Chamados" no menu
- Veja o status: 🔴 A Fazer → 🔵 Em Andamento → 🟢 Concluído
- Converse com o técnico pelo chat

---

## 🔧 Para Técnicos de TI

### Gerenciar chamados

1. Visualize os chamados no **Kanban**
2. Arraste para alterar o status
3. Clique para ver detalhes e responder
4. Fixe chamados importantes com 📌

### Criar alertas globais

- Menu → Alertas → Novo Alerta
- Escolha: Info | Aviso | Crítico
